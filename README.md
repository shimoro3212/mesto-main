# Mesto — shimoro3212

Проектная работа «Место. Работа с сервером»: адаптивный сервис обмена фотографиями.
Профиль и карточки загружаются из API Практикума. Исходники хранятся в закрытом
репозитории shimoro3212/mesto-main, сборка публикуется отдельно.

## Возможности

- Загрузка профиля и карточек через Promise.all.
- Редактирование имени, описания и аватара с сохранением на сервере.
- Добавление карточек в начало списка, удаление своих карточек с подтверждением.
- Лайки и их количество по ответам сервера.
- Просмотр фотографии и информации о карточке: описание, дата, автор,
  количество лайков и имена пользователей, поставивших лайк.
- Валидация форм, индикаторы отправки, защита от повторных отправок и вывод ошибок.
- Закрытие окон кнопкой, нажатием Escape или кликом по фону.

## Запуск и сборка

Требуется Node.js 22.12 или новее.

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env.local`.
3. Заполните VITE_MESTO_COHORT и VITE_MESTO_TOKEN личными данными Практикума.
4. Выполните `npm run dev`.

```sh
npm run dev      # локальный сервер, открытие страницы в браузере
npm run build    # сборка в dist
npm run preview  # просмотр сборки
npm run deploy   # сборка и публикация в shimoro3212/mesto-production, ветка main
```

Файл .env.local исключён из Git. Переменные Vite попадают в клиентскую сборку:
токен учебного API доступен браузеру, поэтому сюда нельзя подставлять токен GitHub.

## Публикация

Адрес GitHub Pages после включения публикации:
https://shimoro3212.github.io/mesto-production/

В публичный mesto-production отправляется только содержимое dist.
Для ручной публикации нужен доступ Git к этому репозиторию. В его Settings → Pages
укажите Deploy from a branch, ветку main и папку / (root).

Для автоматической публикации из закрытого репозитория добавьте в Settings →
Secrets and variables → Actions:

- VITE_MESTO_COHORT — ID учебной группы;
- VITE_MESTO_TOKEN — токен учебного API;
- PUBLIC_PAGES_TOKEN — токен GitHub с правом записи в репозиторий сборки;
- PUBLIC_PAGES_REPO — shimoro3212/mesto-production (значение по умолчанию);
- PUBLIC_PAGES_BRANCH — необязательно, по умолчанию main.

Workflow .github/workflows/deploy.yml устанавливает зависимости, проверяет данные
API и собирает проект при push в main или ручном запуске. Публикация выполняется
при наличии PUBLIC_PAGES_TOKEN.

## Структура

src/scripts/index.js — инициализация и обработка ответов сервера.
src/scripts/components/ — API, карточки, модальные окна и валидация.
src/blocks/ — стили БЭМ, src/images/ и src/vendor/ — изображения и шрифты.

Основа оформления и структуры: https://github.com/buran27/mesto-main.
