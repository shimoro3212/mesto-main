# Mesto — shimoro3212

Проектная работа «Место. Работа с сервером»: адаптивный сервис обмена фотографиями.
Профиль и карточки загружаются из API Практикума. Исходники хранятся в закрытом
репозитории shimoro3212/mesto-main, сборка публикуется отдельно.

## Возможности

- Загрузка профиля и карточек через Promise.all.
- Редактирование имени, описания и аватара с сохранением на сервере.
- Добавление карточек в начало списка, удаление своих карточек с подтверждением.
- Лайки и их количество по ответам сервера.
- Просмотр фотографии и информации о карточке: описание, дата, автор,
  количество лайков и имена пользователей, поставивших лайк.
- Валидация форм, индикаторы отправки, защита от повторных отправок и вывод ошибок.
- Закрытие окон кнопкой, нажатием Escape или кликом по фону.

## Запуск и сборка

Требуется Node.js 22.12 или новее.

1. Установите зависимости: `npm ci`.
2. Выполните `npm run dev`.

Учебная группа и токен Mesto уже настроены в api.js, как предусмотрено заданием.
Скачанный код запускается без создания дополнительных файлов.
При необходимости можно переопределить данные через VITE_MESTO_COHORT и
VITE_MESTO_TOKEN в .env.local; образец находится в .env.example.

```sh
npm run dev      # локальный сервер, открытие страницы в браузере
npm run build    # сборка в dist
npm run preview  # просмотр сборки
npm run deploy   # сборка и публикация в shimoro3212/mesto-production, ветка main
```

Файл .env.local исключён из Git. Токен учебного API доступен браузеру,
поэтому сюда нельзя подставлять токен GitHub.

## Публикация

Сайт на GitHub Pages:
https://shimoro3212.github.io/mesto-production/

В публичный mesto-production отправляется только содержимое dist.
Для ручной публикации нужен доступ Git к этому репозиторию. В его Settings → Pages
укажите Deploy from a branch, ветку main и папку / (root).

Автоматическая публикация настроена. При push в main исходного репозитория
GitHub Actions собирает проект и отправляет сборку в mesto-production.
Для публикации используется отдельный SSH-ключ с правом записи только в
репозиторий сборки, без персонального токена с доступом ко всем репозиториям.
В Settings → Secrets and variables → Actions исходного репозитория настроены:

- VITE_MESTO_COHORT — ID учебной группы;
- VITE_MESTO_TOKEN — токен учебного API;
- MESTO_PAGES_DEPLOY_KEY — ключ публикации в репозиторий сборки;
- PUBLIC_PAGES_REPO — shimoro3212/mesto-production (значение по умолчанию);
- PUBLIC_PAGES_BRANCH — необязательно, по умолчанию main.

Workflow .github/workflows/deploy.yml устанавливает зависимости и собирает проект
при push в main или ручном запуске. Публикация выполняется при наличии ключа и
обоих параметров учебного API.

## Вариант 1 — статистика карточки

Кнопка «i» получает свежий список карточек с сервера и находит выбранную карточку
по ID. Окно показывает описание, дату создания в русском формате, владельца,
количество лайков и список пользователей, поставивших лайк. Строки информации
и пользователи создаются из готовых HTML-шаблонов.

## Структура

src/scripts/index.js — инициализация и обработка ответов сервера.
src/scripts/components/ — API, карточки, модальные окна и валидация.
src/blocks/ — стили БЭМ, src/images/ и src/vendor/ — изображения и шрифты.

## Перед сдачей на ревью

Ссылка на исходники: https://github.com/shimoro3212/mesto-main/tree/main.
В ветке main должны присутствовать:

- src/scripts/components/api.js — запросы к серверу;
- src/scripts/components/validation.js — валидация всех форм;
- src/scripts/components/card.js — карточки и обработчик кнопки «i»;
- src/scripts/components/modal.js — работа модальных окон;
- src/scripts/index.js — инициализация и заполнение окна статистики.

Предустановленного массива src/scripts/cards.js в проекте нет:
карточки загружаются с сервера. Для сдачи используется репозиторий исходников,
а не публичный репозиторий сборки mesto-production. После обновления ветки main
нужно отправить новую версию через страницу сдачи в Практикуме, чтобы снимок кода
на проверке обновился. Доступ ревьюера к закрытому репозиторию должен быть разрешён
через подключение GitHub в Практикуме.

Основа оформления и структуры: https://github.com/buran27/mesto-main.
